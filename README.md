# Mazia Dashboard (VoixUp)

A modern AI Call Agent dashboard for managing and monitoring Mazia, the intelligent voice assistant.
This dashboard allows users to track call activity, manage AI behavior, and interact with the AI call agent through a clean and responsive interface.

Built with React + Vite, styled using Tailwind CSS, and designed for a smooth, professional user experience.


## Tech Stack

React

Vite

Tailwind CSS

### Installation

# Clone the repository

git clone https://github.com/Itsnotxarwa/dashboard.git

## Navigate to the project folder

cd dashboard

### Install dependencies

npm install

#### Run the development server

npm run dev


Open http://localhost:5173/dashboard in your browser to view the dashboard.
